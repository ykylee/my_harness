# Provider Auto-Configuration Skill

## Purpose

LLM provider 의 가용성은 **환경 / 조직 / 시점**에 따라 다름. 하드코딩된 fallback list 는:
- API key 가 없으면 fail
- local LLM 이 꺼져 있으면 fail
- 새 provider 추가 시 코드 변경 필요

→ **런타임 discovered list** 로 fallback chain 동적 구성. 사용자 개입 최소화.

## Auto-Invoke Triggers

| trigger | 동작 |
| --- | --- |
| `myharness` startup | discover phase 자동 실행 (cached state + refresh) |
| `myharness auth <provider> login` | 해당 provider auth 완료 → active list rebuild |
| `myharness auth <provider> logout` | active list 에서 제거 |
| `myharness auth <provider> set-key` | auth state 갱신 → active list rebuild |
| fallback 실패 시 | 해당 provider `status=error` 표시 + 다음 fallback 자동 시도 |
| `myharness auth setup` | 모든 provider 일괄 discover + login wizard |

## Capabilities

### 1. Discover (런타임 발견)

각 provider 별 auto-detect 로직:

| provider | env var | keychain service | local server check |
| --- | --- | --- | --- |
| `anthropic` | `ANTHROPIC_API_KEY` | `claude.ai` 또는 `anthropic` | — |
| `openai` | `OPENAI_API_KEY` | `openai` | — |
| `gemini` | `GOOGLE_API_KEY` / `GEMINI_API_KEY` | `google` | — |
| `deepseek` | `DEEPSEEK_API_KEY` | `deepseek` | — |
| `minimax` | `MINIMAX_API_KEY` (TBD) | `minimax` (TBD) | — |
| `ollama` | — | — | `GET http://localhost:11434/api/tags` |
| `vllm` | — | — | `GET http://localhost:8000/v1/models` |
| `lm-studio` | — | — | `GET http://localhost:1234/v1/models` |
| `llama.cpp` | — | — | `GET http://localhost:8080/v1/models` |

### 2. Auth State (per-provider status)

`~/.myharness/state/auth/<provider>.toml` — 각 provider 의 현재 상태.

**status 값**:
- `authenticated` — API key/oauth + model list 확인
- `logged_out` — auth 안 됨 (or expired)
- `error` — 마지막 호출 실패 (test result fail)
- `not_configured` — env/keychain/local 어디에도 없음
- `local_available` — local server (Ollama/vLLM) 실행 중, models 발견

### 3. Per-Provider Auth Functions

```rust
// src/auth/mod.rs (Rust 1안)
pub trait ProviderAuth {
    async fn discover() -> Result<AuthState>;
    async fn login(&mut self) -> Result<()>;       // OAuth flow or API key prompt
    async fn logout(&mut self) -> Result<()>;
    async fn set_key(&mut self, key: &str) -> Result<()>;
    async fn test(&self) -> Result<TestResult>;
    async fn available_models(&self) -> Result<Vec<ModelInfo>>;
}
```

**구현 (per provider)**:
- `anthropic` — API key (env or keychain), test = `POST /v1/messages` (minimal)
- `openai` — API key, test = `GET /v1/models`
- `gemini` — API key, test = `GET /v1beta/models`
- `deepseek` — API key, test = `GET /v1/models`
- `minimax` — API key (TBD), test = provider-specific
- `ollama` — no auth, test = `GET /api/tags`
- (vLLM / LM Studio / llama.cpp) — no auth, test = `GET /v1/models`

### 4. Active Providers List (런타임 fallback source)

`~/.myharness/state/auth/active-providers.toml` — 현재 사용 가능한 providers 의 우선순위 list.

```toml

```

## CLI Interface

```bash
# 조회
myharness auth list                              # 모든 provider status table
myharness auth <provider>                        # 한 provider 상세
myharness auth show-active                       # active-providers.toml 내용

# 설정
myharness auth <provider> login                  # OAuth or API key prompt
myharness auth <provider> logout                 # auth 제거
myharness auth <provider> set-key <key>          # API key 수동 설정
myharness auth <provider> set-key --from-keychain # OS keychain 에서 import
myharness auth <provider> test                   # 연결 테스트 (ping)

# Wizard
myharness auth setup                              # 모든 provider 일괄 discover + login

# Override
myharness auth default <provider>                 # primary 변경 (config)
myharness auth set-priority <provider> <N>        # priority 조정 (config)
```

## Fallback Chain 동작

```
LLM call 요청
   ↓
1. active-providers.toml 의 priority=1 provider 시도
   ↓ (실패 시)
2. priority=2 provider 시도
   ↓ (실패 시)
3. priority=3 provider 시도
   ...
   ↓ (모두 실패 시)
4. error surface to user (with retry hint)
```

**Failure 처리 (D-15, claude-code 2.1.166)**:
- **즉시 surface**: auth / rate_limit / request_size / transport
- **retry-able**: overloaded / timeout / transient → 1회 fallback retry
- **permanent fail**: status=error 로 표시, 다음 호출 시 skip

## v1 Sample SKILL Implementation (Rust)

```rust
// src/skills/provider_auto_config.rs (Phase 1 간소화 버전)
pub async fn discover_providers(config: &Config) -> Vec<ProviderState> {
    let mut states = Vec::new();
    
    for provider in &config.providers {
        let state = match provider.name.as_str() {
            "anthropic" => discover_anthropic(provider).await,
            "openai" => discover_openai(provider).await,
            "gemini" => discover_gemini(provider).await,
            "deepseek" => discover_deepseek(provider).await,
            "minimax" => discover_minimax(provider).await,
            "ollama" => discover_ollama(provider).await,
            _ => continue,
        };
        states.push(state);
    }
    
    // active list 갱신
    update_active_providers(&states).await;
    states
}

async fn discover_anthropic(p: &ProviderConfig) -> ProviderState {
    let api_key = read_secret(&p.api_key_env, &p.secret_store).await;
    if let Some(key) = api_key {
        let test = test_anthropic(&key).await;
        ProviderState {
            provider: p.name.clone(),
            status: if test.is_ok() { AuthStatus::Authenticated } else { AuthStatus::Error },
            default_model: p.models[0].clone(),
            test_result: Some(test),
            ..Default::default()
        }
    } else {
        ProviderState {
            provider: p.name.clone(),
            status: AuthStatus::NotConfigured,
            ..Default::default()
        }
    }
}

async fn discover_ollama(p: &ProviderConfig) -> ProviderState {
    let url = p.base_url.as_deref().unwrap_or("http://localhost:11434/v1");
    match reqwest::get(format!("{}/api/tags", url.replace("/v1", ""))).await {
        Ok(resp) if resp.status().is_success() => {
            let models: Vec<String> = resp.json().await.unwrap_or_default();
            ProviderState {
                provider: "ollama".into(),
                status: AuthStatus::LocalAvailable,
                base_url: Some(url.into()),
                discovered_models: models,
                default_model: "qwen2.5-coder:32b".into(),
                ..Default::default()
            }
        }
        _ => ProviderState {
            provider: "ollama".into(),
            status: AuthStatus::NotConfigured,
            ..Default::default()
        }
    }
}
```
